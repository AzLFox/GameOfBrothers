# Баг B5 — двуручное оружие затирает предмет в другой руке

**Ветка:** `fix/b5-two-handed-hand-guard` (от `develop`, merge в `develop`)
**Цель:** двуручное оружие больше **нельзя** экипировать в руку, если вторая рука занята
самостоятельным предметом. Вместо тихого удаления соседнего предмета — запрет выбора
двуручного класса (в редакторе слота) и запрет дропа (перетаскивание из рюкзака) с понятной
индикацией. Одноручное оружие, щиты и уже собранная двуручная связка работают как прежде.

Каждая фаза — отдельная сессия работы. Выполнять по порядку.

## Причина (по коду)

- При установке двуручного класса в руку `reconcileHands`
  ([../public/js/character.js:3694](../public/js/character.js#L3694)) пишет зеркало во вторую руку:
  `sheet.equipment[other] = mirror` ([:3702](../public/js/character.js#L3702)) — предмет, который
  там лежал, молча перезаписывается.
- Два входа, ведущие сюда с **новым** занятием второй руки двуручным оружием:
  1. Пикер класса редактора слота — `setItemClass` ([:3713](../public/js/character.js#L3713))
     → `reconcileHands`.
  2. Перетаскивание/тап-перенос из рюкзака — `equipFromBackpack`
     ([:2377](../public/js/character.js#L2377)) → `reconcileHands`; допуск дропа считает
     `canEquipBackpackItemToSlot` ([:2358](../public/js/character.js#L2358)).
- Прочие вызовы `reconcileHands` (правка тира/модов/названия, очистка слота, перенос
  снаряжение→рюкзак) двуручность руки **не** меняют — новых занятий второй руки не создают, их не
  трогаем.
- Хороший ориентир уже есть: миграция старых сохранений отражает двуручное оружие во вторую руку
  **только если она пуста** ([:1416](../public/js/character.js#L1416)) — тот же принцип «не
  затирать» распространяем на живую экипировку.

## Принципы

- **Запрет, а не тихое удаление.** Двуручное оружие недоступно, пока вторая рука занята
  самостоятельным предметом. Это ровно поведение, описанное в [BUGS.md](BUGS.md) (B5).
- **Единый предикат, а не спецкейсы по местам.** Одна чистая проверка
  `otherHandBlocksTwoHanded(slotKey)` обслуживает оба входа (пикер и дроп) — не размазываем условие
  по коду.
- **«Занята» = самостоятельный предмет.** Вторая рука блокирует, если там непустой предмет,
  **не** являющийся зеркалом текущей связки. Зеркало (`item.mirror`) блокировать нельзя — иначе
  нельзя будет менять уже надетое двуручное оружие само на себя/на другой двуручный класс.
- **Одноручное / щит / смена тира — без изменений.** Гард срабатывает только на двуручные классы
  (`hands === 2`) при новом занятии второй руки.
- **Фронтенд без сборки, ванильные `GobXxx`** — не переписывать на фреймворк; игровые формулы листа
  (`maxHp = str×4 + hpBonus` и т. п.) не трогать.
- **Интеграция в существующую индикацию дропа.** Для перетаскивания отдельный код подсветки не
  нужен: `canEquipBackpackItemToSlot` уже питает `item-slot--drop-invalid`/вибрацию — достаточно
  вернуть из него `false`.

## Предикат (что добавляем)

```js
// Вторая рука занята самостоятельным предметом → двуручное оружие в этот слот брать нельзя
// (иначе reconcileHands молча затрёт соседний предмет — BUGS.md B5).
// Редактируемый слот-зеркало не в счёт: вторая рука — владелец той же связки.
function otherHandBlocksTwoHanded(slotKey) {
  if (!isHandSlot(slotKey)) return false;
  if (sheet.equipment[slotKey]?.mirror) return false;
  const otherItem = sheet.equipment[otherHand(slotKey)];
  return !isItemEmpty(otherItem) && !otherItem.mirror;
}
```

## Smoke-сценарии (приёмка)

1. **Пикер: занятая рука блокирует.** Лист с одноручным мечом в левой руке и щитом в правой. Открыть
   редактор правой руки → двуручные классы (Сила 2р, Ловкость 2р, Арбалет 2р, Лук 2р, Посох)
   disabled, под селектом заметка «…левая рука занята». Меч в левой руке на месте.
2. **Пикер: свободная рука разрешает.** Освободить левую руку → в редакторе правой двуручные классы
   снова активны; выбрать «Сила (2р)» → оружие занимает обе руки (зеркало).
3. **Смена уже надетого двуручного.** У собранной двуручной связки открыть редактор слота-владельца →
   двуручные классы активны, тир меняется, зеркало пересобирается.
4. **Дроп на занятую руку заблокирован.** Щит в левой руке, двуручный меч в рюкзаке. Тащить меч на
   правую руку → слот красный, дроп не проходит, щит цел.
5. **Дроп на свободную руку проходит.** Освободить левую руку, тащить меч на правую → меч в обеих
   руках, регресса нет.

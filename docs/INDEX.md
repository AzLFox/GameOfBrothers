# INDEX.md — карта документации

> **Назначение.** Единая точка входа в документы-инструкции проекта GameOfBrothers — для тебя
> (ассистента) и любого разработчика. Отсюда видно, где что искать.
> **Содержимое.** Ссылки на все рабочие/инструктивные документы с однострочным описанием.
> Все документы лежат в `docs/` и коммитятся в git (бэкап + онбординг новых разработчиков).
> Единственное исключение — [../CLAUDE.md](../CLAUDE.md) в корне (его автоматически подхватывает
> Claude Code), он лишь указывает сюда.

---

## Рабочие документы (состояние проекта)

- [../CLAUDE.md](../CLAUDE.md) — инструкции ассистенту; лежит в корне, указывает на этот индекс.
- [BUGS.md](BUGS.md) — реестр подтверждённых багов (что сейчас работает неправильно).
- [TO-DO.md](TO-DO.md) — предложения по развитию: новые возможности, улучшения, тех-долг.
- [TO-BS.md](TO-BS.md) — на подумать (brainstorm): темы для обсуждения, по которым решения ещё нет.
- [TO-DEL.md](TO-DEL.md) — файлы-кандидаты на удаление (мусор/артефакты) с обоснованием.

## Проектная документация (спецификации и планы)

- [auth-roadmap.md](auth-roadmap.md) — план по аутентификации.
- [create-hero-roadmap.md](create-hero-roadmap.md) — план по созданию героя.
- [visual-roadmap.md](visual-roadmap.md) — визуальный роадмап (десктоп).
- [mobile-visual-roadmap.md](mobile-visual-roadmap.md) — визуальный роадмап (мобильный).

> **Новые фичи планируем роадмапом.** Для каждой крупной возможности заводим
> `docs/<slug>-roadmap.md` в едином формате (шапка → Принципы → Фазы с промптом и
> критериями → Порядок → Быстрые правила). Оформление — через навык `feature-roadmap`
> ([.claude/skills/feature-roadmap/SKILL.md](../.claude/skills/feature-roadmap/SKILL.md));
> шаблон — `.claude/skills/feature-roadmap/assets/roadmap-template.md`. Новый роадмап
> добавляй строкой в этот список.

## Ориентиры по коду

- [../package.json](../package.json) — скрипты запуска и зависимости.
- `server/` — бэкенд (Express): [../server/server.js](../server/server.js),
  [../server/store.js](../server/store.js), [../server/auth.js](../server/auth.js);
  данные — `server/data/` (в `.gitignore`).
- `public/` — фронтенд (ванильный JS + HTML/CSS): страницы `*.html`, логика `js/`, стили `css/`.
- `scripts/` — офлайн-тулинг для обработки/генерации ассетов (запускается вручную).

# GoB Visual Roadmap — промпты для реализации

Цель: удобный и красивый UI для настольной DnD-сессии (не игра-движок).
Приоритеты: **кинематографичный UI** + **живая главная сцена**.
Стек: HTML/CSS/JS + GSAP (+ Pixi.js на главной, фаза 4).

Каждый промпт — отдельная сессия работы. Выполнять по порядку.

---

## Фаза 1 — Фундамент motion (✅ готово)

**Промпт:**
> В проекте GoB (ветка `project_rethinking`) заложи фундамент для кинематографичного UI:
> 1. Подключи GSAP через npm и `/vendor/gsap`.
> 2. Создай `public/css/gob-tokens.css` — цвета, типографика, длительности, easing-пресеты.
> 3. Создай `public/js/gob-motion.js` — общий API: `prefers-reduced-motion`, easing, `timeline()`, хелперы `fadeUp`, `staggerIn`, `pulseGlow`.
> 4. На главной (`index.html` / `index.js`) замени ручные `requestAnimationFrame`-анимации карусели и флипа карточки на GSAP.
> 5. Добавь GSAP intro-timeline: завесы → горы → дерево → заголовок → карточки (stagger).
> Не трогай лист персонажа. Сохрани текущий визуальный стиль, улучши плавность и синхронность.

**Критерии готовности:**
- [ ] GSAP доступен на всех страницах через общий путь
- [ ] `gob-motion.js` переиспользуется без дублирования easing
- [ ] Открытие/закрытие карточки на главной — GSAP timeline
- [ ] Intro воспроизводится один раз, уважает `prefers-reduced-motion`

## Фаза 2 — Кинематографичный UI: главная страница (✅ готово)

**Промпт:**
> Доведи главную страницу GoB до кинематографичного уровня на GSAP:
> 1. Закрытие карточки — обратный timeline (не мгновенный сброс): spotlight fade, flip back, carousel expand, overlay out.
> 2. Hover/focus на карточках в орбите — лёгкий `translateZ` + glow без ломания `rear`-логики.
> 3. Кнопка «Новый персонаж» — micro-interaction (shine sweep, scale).
> 4. Переход по «Открыть» — page-out: затемнение + scale карточки → navigate (или fade всей сцены).
> 5. Синхронизировать `card-select.mp3` с пиком анимации (не с началом).
> Сохрани 3D-карусель и центрирование. Не добавляй Pixi пока.

**Критерии готовности:**
- [ ] Close-card так же красив, как open-card
- [ ] Нет рывков при смене `rear` во время анимации
- [ ] Переход на `/character` ощущается как «сцена из игры»

## Фаза 3 — Кинематографичный UI: лист персонажа (✅ готово)

**Промпт:**
> Подключи `gob-tokens.css` и `gob-motion.js` к `character.html`. Сделай кинематографичный UI листа персонажа:
> 1. Page-enter: портрет → статы → бой → экипировка → рюкзак (stagger 80–120ms).
> 2. Спеллбук: перелистывание страниц — GSAP timeline (угол страницы, тень, звук опционально).
> 3. Модалки/редактор слотов — slide+fade слева, не резкое появление.
> 4. Combat tooltips — fade+slide, без скачков позиции.
> 5. Числовые поля HP/AP/MP — мягкий flash при изменении (цвет 300ms).
> Не менять игровую логику и формулы. Только motion-слой поверх существующего JS.

**Критерии готовности:**
- [ ] Открытие спеллбука ощущается как книга, не как dialog
- [ ] Редактор слота не «прыгает»
- [ ] Все анимации отключаются при `prefers-reduced-motion`

## Фаза 4 — Живая главная сцена (Pixi.js) (✅ готово)

**Промпт:**
> Добавь на главную GoB живую атмосферу через Pixi.js (только `index.html`, canvas под `.scene`):
> 1. Fullscreen canvas `pointer-events: none`, z-index между `realm-depth` и каруселью.
> 2. Частицы: мотыльки/искры вокруг `world-tree` (teal + gold, low count для perf).
> 3. Мягкое пульсирующее свечение у корней дерева (radial gradient sprite или filter).
> 4. Реакция на выбранную карточку: чуть больше частиц + теплее свечение.
> 5. `prefers-reduced-motion` → статичный лёгкий glow без частиц.
> Карусель и клики не ломать. Pixi не трогать character page.

**Критерии готовности:**
- [ ] 60fps на средней машине, < 200 частиц
- [ ] Canvas resize на window resize
- [ ] Дерево и карточки визуально «в одном мире»

## Фаза 5 — Звук, полировка, общие переходы (✅ готово)

**Промпт:**
> Финальная полировка motion в GoB:
> 1. Единый звуковой слой: hover, open, close, page flip (громкость + throttle).
> 2. Общий page-transition helper в `gob-motion.js` для index ↔ character ↔ create.
> 3. Loading state при fetch `/api/characters` — skeleton/shimmer карточек вместо пустоты.
> 4. Performance pass: `will-change` только на время анимации, kill tweens on navigate.
> 5. Пройтись по mobile (640px): intro короче, меньше частиц.

**Критерии готовности:**
- [x] `gob-sound.js` — процедурный Web Audio, throttle, unlock на первый клик
- [x] `GobMotion.navigateTo()` на главной, листе и create
- [x] Skeleton/shimmer карусели во время fetch
- [x] `will-change` на карусели и флипе карточки
- [x] Mobile: короче intro, меньше частиц в Pixi

## Фаза 6 — Арт-направление (✅ готово)

**Промпт:**
> Усиль визуальную целостность GoB без смены стека:
> 1. Единый набор рамок (9-slice PNG) для панелей листа и карточек.
> 2. Фоновая текстура пергамента для `card-content` и панелей статов.
> 3. Иконки спелов — без изменения существующих (только добавление новых при необходимости).

> Референс: HoMM3 UI + BG3 character sheet, но читаемость для сессии за столом.

**Критерии готовности:**
- [x] SVG 9-slice рамки (`frame-panel.svg`, `frame-card.svg`) + `gob-art.css`
- [x] Пергаментная текстура на панелях листа и `card-content`
- [x] Контраст текста: `--gob-text-body` / `--gob-text-muted` (WCAG AA на пергаменте)
- [x] Иконки спелов без изменений — используются оригинальные `.png` из `character.css`
